# City Select

A city recommendation tool that scores and ranks cities based on your personal priorities to help you find the best place to live.

## How it works

1. **Start the quiz** — or jump straight to a side-by-side city comparison
2. **Rank your priorities** — drag dimensions into the order that matters to you
3. **Take a short quiz** — answers tune the scoring (climate preferences, career focus, budget, language, etc.)
4. **See your results** — top 5 ranked cities with scores, strengths, and weaknesses, plus a full ranked table of all cities. Hover any score to see where the city ranks and which real source the number comes from (e.g. "Copenhagen is 63rd of 250 cities for coldest winters — source: NASA POWER")

Scoring is a weighted average across 19 dimensions (safety, cost of living, air quality, healthcare, etc.). Your priority ranking and quiz answers adjust the weights.

Every score comes from a real third-party source — nothing is hand-estimated. When a source has no data for a city, that dimension is **skipped** for that city (the weighted average renormalizes over the dimensions that have data) and the city shows a coverage badge like "17/19 data".

## Running locally

The app is plain HTML/CSS/JS with no build step. It uses ES modules, so it must be served over HTTP (not opened as a `file://` URL).

```bash
# Python 3 (simplest)
python serve.py
# then open http://localhost:8000

# Or any static server:
npx serve .
```

## Updating the data

All city scores are compiled from authoritative third-party datasets. The pipeline lives in `data/`.

### Step 1 — Download sources

```bash
cd data
python sources/download.py
```

This fetches everything:

| File | Source | Dimensions |
|------|--------|------------|
| `ti_cpi.csv` | World Bank WGI (Control of Corruption) | `corruption` |
| `sipri.csv` | World Bank (Military Expenditure % GDP) | `militarySpending` |
| `henley.csv` | Passport Index open dataset (GitHub) | `visaEase` |
| `rsf.csv` | RSF World Press Freedom Index (official CSV) | `pressFreedom` |
| `ookla.csv` | Ookla Speedtest Global Index (fixed broadband) | `internetQuality` |
| `ef_epi.csv` | EF English Proficiency Index | `languageAccess` |
| `numbeo_col.csv` | Numbeo Cost of Living rankings | `costOfLiving` |
| `numbeo_property.csv` | Numbeo Price-to-Income rankings | `affordability` |
| `numbeo_crime.csv` | Numbeo Crime Index rankings | `safety` |
| `who_air.csv` | WHO Ambient Air Quality Database (city PM2.5) | `airQuality` |
| `freedom_house.csv` | Freedom House Freedom in the World | `govProgressiveness` |
| `who_uhc.csv` | WHO UHC Service Coverage Index | `healthcareQuality` |
| `wb_hlo.csv` | World Bank Harmonized Learning Outcomes | `educationQuality` |
| `wb_gdp.csv` | World Bank real GDP growth (3-yr avg) | `economicOutlook` |
| `owid_fossil.csv` | OWID/Ember fossil share of electricity | `fossilFuelReliance` |
| `climate_data.csv` | NASA POWER climate normals API | `sunshine`, `humidity`, `rainfall`, `winterWarmth` |

See `data/sources/README.md` for details on each source and its transform.

### Step 2 — Compile cities.csv

```bash
python data/build.py
```

This merges all source files into `data/cities.csv`. When a source has no data for a city, the cell is left **empty** — the app skips that dimension for that city and shows a coverage badge. No scores are ever fabricated.

## Adding a new city

1. Add a row to `data/sources/city_meta.csv` — include `id`, `name`, `country`, `region`, `population`, `climate`, `industries`, `primaryLanguage`, `gdpPerCapita`, `density`, `nickname`, `lat`, `lon`
2. Add city name variants to `data/sources/city_mappings.csv` (for Numbeo matching)
3. If the city is in a new country, add a row to `data/sources/country_mappings.csv`
4. Run `python data/sources/download.py` then `python data/build.py`

City IDs must be camelCase with no spaces (e.g. `newYork`, `kualaLumpur`).

## Dimensions

19 dimensions, all scored 0–100 (higher = better). Country-level dimensions apply the same score to every city in that country. City-level dimensions are unique per city.

Weights, rankability, and hover-tooltip metadata (`source`, `highLabel`, `lowLabel` — e.g. "warmest winters" / "coldest winters") are defined in `data/dimensions.csv`. All source data is fetched by `download.py` and compiled by `build.py`.

| Dimension | Level | Source | How it's scored |
|-----------|-------|--------|-----------------|
| **corruption** | country | [World Bank WGI](https://info.worldbank.org/governance/wgi/) — Control of Corruption (`GOV_WGI_CC.SC`) | Governance score, natively 0–100 (higher = cleaner). Used directly |
| **pressFreedom** | country | [RSF World Press Freedom Index](https://rsf.org/en/index) — official CSV | Score 0–100 (higher = more free). Used directly |
| **militarySpending** | country | [World Bank](https://data.worldbank.org/indicator/MS.MIL.XPND.GD.ZS) — military expenditure % of GDP | Inverted: `100 − clamp(pct / 5 × 100)`. 0% GDP → 100, 5%+ → 0 |
| **visaEase** | country | [Passport Index](https://github.com/ilyankou/passport-index-dataset) open dataset | Count of visa-free + visa-on-arrival destinations, normalized to 193 max |
| **costOfLiving** | city | [Numbeo Cost of Living Index](https://www.numbeo.com/cost-of-living/rankings.jsp) | NYC baseline ≈ 100. Inverted and normalized to observed range — lower cost → higher score |
| **affordability** | city | [Numbeo Price-to-Income Ratio](https://www.numbeo.com/property-investment/rankings.jsp) | Higher ratio = less affordable. Inverted and normalized (capped at 40) |
| **safety** | city | [Numbeo Crime Index](https://www.numbeo.com/crime/rankings.jsp) | `100 − crime_index`. Lower crime → higher score |
| **airQuality** | city | [WHO Ambient Air Quality Database](https://www.who.int/data/gho/data/themes/air-pollution/who-air-quality-database) — city PM2.5, geo-matched | `clamp((50 − pm25) / 50 × 100)`. WHO guideline is 5 µg/m³; at 50 µg/m³ score hits 0 |
| **internetQuality** | country | [Ookla Speedtest Global Index](https://www.speedtest.net/global-index) — median fixed broadband Mbps | `clamp(mbps / 200 × 100)`. 200+ Mbps → 100 |
| **languageAccess** | city | [EF English Proficiency Index](https://www.ef.com/wwen/epi/) | English-primary cities → 100. Others use the country EPI score rescaled to 0–100 |
| **govProgressiveness** | country | [Freedom House Freedom in the World](https://freedomhouse.org/report/freedom-world) | Aggregate FIW score 0–100 (higher = more free). Used directly |
| **healthcareQuality** | country | [WHO UHC Service Coverage Index](https://www.who.int/data/gho/data/indicators/indicator-details/GHO/uhc-index-of-service-coverage) | Index 0–100, latest year per country. Used directly |
| **educationQuality** | country | [World Bank Harmonized Learning Outcomes](https://data.worldbank.org/indicator/HD.HCI.HLOS) | Harmonized test scores (~300–625) rescaled: `(score − 300) / 300 × 100` |
| **economicOutlook** | country | [World Bank real GDP growth](https://data.worldbank.org/indicator/NY.GDP.MKTP.KD.ZG) | 3-year average growth mapped: `(avg + 2) / 8 × 100`. −2% → 0, +6% → 100 |
| **fossilFuelReliance** | country | [OWID/Ember — fossil share of electricity](https://ourworldindata.org/grapher/share-electricity-fossil-fuels) | `100 − fossil share of electricity generation` |
| **sunshine** | city | [NASA POWER](https://power.larc.nasa.gov/) — multi-year solar irradiance climatology | Annual mean solar irradiance (kWh/m²/day) converted to ~sunshine hours, then `clamp((hours − 1000) / 2500 × 100)` |
| **humidity** | city | NASA POWER — relative humidity climatology | Annual mean RH %: `clamp((rh − 30) / 55 × 100)`. 30% → 0, 85% → 100 |
| **rainfall** | city | NASA POWER — precipitation climatology | Annual total mm: `clamp(mm / 2500 × 100)`. 0mm → 0, 2500mm → 100 |
| **winterWarmth** | city | NASA POWER — temperature climatology | January mean °C: `clamp((jan + 20) / 45 × 100)`. −20°C → 0, +25°C → 100 |

### Missing data is skipped, never guessed

When a source has no data for a city (e.g. Numbeo only ranks ~400–550 cities; WHO air data skips some countries), that cell is empty in `cities.csv` and the scoring engine drops the dimension from that city's weighted average. Cities with incomplete data show a coverage badge (e.g. "17/19 data") on their result card and an em dash in score tables.

Dimensions with no verifiable third-party source at all (transit quality, cultural offerings, walkability, nightlife, natural beauty, job market) were removed from the app rather than hand-scored.

## Scoring algorithm

The final score for a city is a weighted average across all active dimensions:

```
effectiveWeight = baseWeight × rankMultiplier × quizMultiplier

score = sum(effectiveWeight × dimScore) / sum(effectiveWeight)
       (over dimensions the city has data for — missing ones are skipped)
```

- **baseWeight** — from `dimensions.csv`
- **rankMultiplier** — 2.0 for your top-ranked dimension, tapering to 0.1 for lowest (positions 0–7: 2.0→1.3, 8–15: 1.0→0.65, 16+: 0.5→0.1)
- **quizMultiplier** — quiz answers can boost specific dimensions (e.g. answering "family with young children" boosts education weight)
- **globalMultiplier** — applied after: climate mismatch (×0.7), language barrier (×0.8–0.9), language match bonus (×1.1), industry mismatch (×0.7)
- **dealbreakers** — a missing dimension never triggers a dealbreaker (no data ≠ bad score)

See `js/scoring.js` for the full implementation.
